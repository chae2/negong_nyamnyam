02 / 직접 따라가기

저장 → 전달 → 처리 → 확인 → 삭제

상황을 고르고 다음 단계를 누르면 메시지의 위치와 상태가 바뀐다. 메시지가 소비자에게 전달된 뒤에도 저장소에 남는 시점을 살펴보자.

시연의 가정: 메시지 M1~M3와 소비자 A·B는 이해를 위한 보충 예시다. 이 시연은 소비자의 처리 성공 후 수신 확인(ACK)을 받고, 그다음 메시지를 저장소에서 삭제한다. 원문 그림에는 ‘수신 확인’과 ‘메시지 삭제’가 표시되어 있지만 확인 시점의 세부 프로토콜은 제시되어 있지 않다.

‘전달 대기’는 저장소에 있는 메시지 중 아직 소비자가 맡지 않은 수다. 전달·처리·확인 단계의 메시지도 삭제 전까지 저장소 개수에 포함한다.

책의 원본 그림 7-1과 함께 읽기

그림의 표기: 원본은 가운데 상자와 오른쪽 상자를 모두 ‘큐 관리자’로 적었다. 본문은 메시지를 처리하는 주체를 ‘소비자’라고 설명한다. 위 시연은 이 역할을 구분하기 위해 오른쪽 처리 주체를 소비자 A·B로 표현했다. 원본의 표기를 그대로 재현한 도식은 아니다.

위 시연의 큰 큐 상자는 역할을 묶어 보여 주는 논리도다. 이 범위에는 실제 서버별 분할·복제 배치나 장애 노드의 선출 절차가 설명되어 있지 않으므로, 특정 제품의 물리 구성을 나타내지 않는다.
